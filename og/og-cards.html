Exporting these as PNGs

Chrome gives you a pixel-exact export without any design tool:

  1. Open this file in Chrome, press F12 for DevTools.
  2. Click the element-picker arrow (top-left of DevTools) and click a card.
  3. In the Elements panel, make sure the highlighted node is the <div class="card ..."> — not a child.
  4. Press Ctrl+Shift+P, type Capture node screenshot, hit Enter.
  5. Save into public/ with the exact filename shown above each card.

Then run npm run build — it verifies each file exists and wires the og:image tags automatically. It will fail loudly if a file is missing, so a broken image can never reach production.

Why 1200×630: that is the 1.91:1 ratio every major platform crops to. Keep important text away from the outer ~60px — some clients crop tighter on mobile, and WhatsApp shows a small square thumbnail in the chat list.
